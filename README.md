## What is an OpenClaw Persona?

[OpenClaw](https://openclaw.ai) is an AI agent platform that turns large language models into autonomous assistants. A **persona** is a complete configuration package that gives your OpenClaw agent a specific professional identity — not just a single prompt, but a full set of structured files:

| File | Role | Required |
|------|------|----------|
| `SOUL.md` | Personality, values, tone — who the agent *is* | **Yes** |
| `AGENTS.md` | Work processes, SOPs, decision rules — how the agent *works* | **Yes** |
| `SKILL.md` | Capabilities, frameworks, output templates — what the agent *can do* | **Yes** |
| `IDENTITY.md` | Name, creature, vibe, emoji — the agent's public identity | Optional |
| `HEARTBEAT.md` | Periodic tasks — what the agent checks on its own | Optional |
| `STYLE.md` | Communication style and formatting rules | Optional |
| `BOOTSTRAP.md` | First-run onboarding conversation flow | Optional |
| `USER.md` | User profile, preferences, and context | Optional |
| `TOOLS.md` | Tool configuration and environment notes | Optional |
| `MEMORY.md` | Long-term curated memory (grows over time) | Optional |

Copy a persona directory into your OpenClaw workspace, and your agent immediately becomes that specialist — with real methodology, not generic advice. No prompt engineering required.

## Structure

Each persona is a directory containing:

```
persona-name/
  SOUL.md        # Personality, values, tone, identity
  AGENTS.md      # Work process, rules, boundaries
  SKILL.md       # Capabilities, deliverables, tools
  IDENTITY.md    # Name, creature, vibe, emoji (optional)
  HEARTBEAT.md   # Periodic task definitions (optional)
  STYLE.md       # Communication style rules (optional)
  BOOTSTRAP.md   # First-run onboarding flow (optional)
  USER.md        # User profile and preferences (optional)
  TOOLS.md       # Tool configuration notes (optional)
  MEMORY.md      # Long-term curated memory (optional)
```

## Contributing

We're building the largest open-source collection of production-ready OpenClaw personas — and we'd love your help.

**What we're looking for:**
- Complete personas with `SOUL.md` + at least `AGENTS.md` or `SKILL.md` (single-file SOUL.md-only submissions will not be accepted)
- Real methodology and domain expertise, not generic prompts
- Personas you've actually used and refined in production

**How to contribute:**
1. Fork this repo
2. Create a new directory under the appropriate category: `personas/[category]/[your-persona-name]/`
3. Add your files (`SOUL.md`, `AGENTS.md`, `SKILL.md`, and any optional files)
4. Include a `README.md` with: name, description, core capabilities, files table, quick start, and use cases
5. Submit a pull request

**Quality bar:** We review every submission. Personas that are essentially system prompts split into files, or that lack actionable frameworks and concrete deliverables, will be asked to add more depth before merging.
